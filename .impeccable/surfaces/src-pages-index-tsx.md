# Surface brief: portfolio home and case studies

Scope: `/` (Hero, About, Work, Experience, Contact, Footer) and `/projects/:id`, plus the overlays every route shares (nav, command palette, assistant dock). Visitor mode: Experience. The work leads; the interface recedes.

Audience: hiring teams and clients, weighted equally; deep-reading engineers third. Two first-class actions: download the CV, and start a conversation about a role or a project.

Constraints: the terminal prompt over the WebGL event horizon stays the hero (user-confirmed). Power features stay but are disclosed progressively. Every figure stays derived or attributable.

## Direction contract

THESIS: The site is a studio monograph of shipped systems, printed on black stock. It refuses the developer-portfolio default of glowing bento cards, tracked mono eyebrows and dashboard chrome; hierarchy comes from scale contrast, hairlines and space.

OWN-WORLD: Black stock #0A0A0A, ink #F2F2F0, caption grey #8A8A8E, hairline #1F1F21, and amber only where something is live or active. Archivo set expanded (stretch ~118%) for titles; Inter for reading; JetBrains Mono only for code, the terminal and measured figures. Square plates, 1px rules, numbered index rows, captions under plates, a colophon. No boxed panels, no chips, no glow.

STORY: First, a person and a working prompt (who he is, and that the site answers back). Then the principles, the plates of selected systems, the full index, the career, and an invitation with two doors: hire, or build together.

FIRST VIEWPORT (final, 2026-10-03, after the user tried a centred hole and asked to return it to the corner for a calmer screen): the page's own stock with a faint distant starfield (three depths, slow twinkle, a rare scintillation and meteor); the ray-traced black hole rising out of the bottom-right corner; at the centre the identity block (name in Archivo, role, Abuja / UTC+1 / availability) over an instrument terminal (caption strip with Shell / Ask switch, the line, a key strip); the four actions below; a derived proof line at the bottom edge.

FORM: Night Monograph, candidate 2 on the grounded list (the pick), seed 599f9600. Raises kept: built work set solid, design-stage work set in hairline outline; filtered rows rerank in place keeping identity; scale contrast instead of boxes; colour only on edges and live state.

SIGNATURE MOTION: the dive through the horizon (existing) is the one authored moment. Everywhere else: plates unveil with a clip-path wipe as they enter, headings rise line by line from a mask, Lenis smooths the wheel. All static under reduced motion.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
